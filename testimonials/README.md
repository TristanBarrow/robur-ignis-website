# Testimonials

One Markdown file per client quote. The body is the quote itself, and the
file name only sets the order on ties (newest `date` comes first).

```md
---
name: Jane Doe
role: Founder, Example Co   # optional
date: 2026-10-09
link: https://www.linkedin.com/in/janedoe   # optional, links the name
---

What they said, in their own words.
```

The section on the home page stays hidden until at least one file exists.
Get the client's permission before adding their name.
